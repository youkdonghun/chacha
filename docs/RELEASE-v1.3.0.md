# Chacha Capture v1.3.0 · Windows x64

단축키 녹화와 실제 등록을 구분하고, 다른 캡처 앱과 함께 사용할 때의 캡처 방식을 개선했습니다.

- 단축키 입력란에 포커스를 두면 즉시 녹화 상태가 표시됩니다. 표준 Windows 키보드 훅을 입력란에 포커스가 있는 동안만 사용해 다른 앱에 등록된 키도 읽습니다. 녹화가 끝나면 훅을 해제합니다.
- 설정 저장 전에 Windows에 실제 등록 가능 여부를 확인합니다. 다른 앱이 사용 중인 키나 예약 키는 설정창 아래에 설명하고 해당 입력란을 선택합니다. 해제로 모든 단축키를 미등록할 수 있습니다.
- 기본 자동 캡처는 GDI 호환 방식부터 사용합니다. 설정에서 호환 방식 또는 GPU Desktop Duplication을 직접 고를 수 있습니다. GPU를 선택했는데 커서 메타데이터 때문에 GDI로 바뀌던 문제를 수정했습니다.
- 단색 프레임을 캡처해도 픽셀을 변경하지 않습니다. 실제 화면과 다르면 다른 방식을 선택하도록 안내하고, 사용 API와 오류를 설정의 진단 복사로 확인할 수 있습니다.
- 대시보드, 설정 입력행, 버튼, 그룹 및 업데이트 화면을 둥근 카드와 여유 있는 배치로 변경했습니다. 실행 버전을 화면에서 확인할 수 있고, 이전 EXE가 실행 중이면 새 파일이 적용되지 않았음을 알려줍니다.
- 캡처 후 자동 플로팅, 선택적 단축키, 주석 및 앱 내 업데이트를 유지합니다.

## 사용

기존 앱을 트레이에서 종료하고 새 `ChachaCapture.exe`를 실행합니다. 설정 → 단축키에서 입력란을 누른 뒤 원하는 키를 누르고 **설정 저장**을 선택합니다. 해제할 기능은 **해제**를 누릅니다.

캡처가 실제 화면과 다르면 설정 → 캡처에서 자동/호환/GPU를 선택해 확인할 수 있습니다. 회사 보안 프로그램과 사용자가 보고한 정확한 충돌 환경은 별도 확인이 필요합니다. 보호된 콘텐츠와 OS 접근 제한을 해제하는 기능은 없습니다.

저장소가 비공개이므로 앱 내 업데이트에는 저장소 접근 권한이 있는 GitHub CLI 로그인 또는 `GH_TOKEN`/`GITHUB_TOKEN`이 필요합니다.
