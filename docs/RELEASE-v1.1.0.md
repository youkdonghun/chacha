# Chacha Capture 1.1.0 · Windows x64

캡처·주석·화면 고정의 단축키와 동작을 Snipaste Windows 무료판 기준으로 확장했습니다.

- Enter 복사 후 종료, Ctrl+T 고정, Ctrl+P 인쇄, Shift+F3 숨기기/표시
- 선택 영역 위 주석 도구 모음, 주석 선택·이동·크기·문자 회전·서체·채움·알파
- 창/UI 요소 감지, 픽셀 이동, 커서 표시 전환, 캡처 기록 재생
- 닫은 이미지 F3 복구, 테두리 배율 조절, Shift 정렬, 다중 선택
- GIF 재생·프레임·속도·변환 상태 저장·복원
- HTML/RTF 기본 서식·TGA·파일 경로 붙여넣기, 투명 PNG 클립보드
- 이미지 그룹과 내보내기·가져오기, 화이트보드, 주요 명령행
- 탭 설정, 빠른 저장·자동 저장, Windows 로그인 시 실행 옵션

EXE 한 개로 실행합니다. Windows 10/11 x64와 .NET Framework 4.8이 필요합니다.
v1.0 기본 숨기기 단축키 Ctrl+F3은 Shift+F3으로 이전하며, 사용자가 바꾼 단축키는 유지합니다.

모든 Snipaste 기능·화면과 완전히 일치하는 버전은 아닙니다. OCR·바코드 등 PRO 기능과 전체 HTML/CSS 렌더링은 포함하지 않습니다.
세부 차이는 [기능 대조표](https://github.com/youkdonghun/chacha/blob/main/docs/PARITY.md)에 명시했습니다.
