# Chacha Capture v1.4.0 · Windows x64

캡처 도중의 도구 표시와 영역 선택을 고치고, 플로팅 단축키가 현재 작업 중인 이미지에 적용되도록 수정했습니다.

- 캡처 위의 그리기 도구에 선택·사각·타원·화살표·펜·문자 등 한국어 이름을 두 줄로 표시합니다. 좁은 기호 버튼과 중복 텍스트 여백 때문에 이름이 잘리던 문제를 수정했습니다.
- 자동 영역 감지를 끄면 창·요소 조회, 강조, 클릭 자동 선택을 모두 중단합니다. 직접 드래그한 영역만 선택하며 Tab이나 휠로 감지가 다시 켜지지 않습니다. 시작 안내도 수동 선택에 맞게 표시합니다.
- 설정한 플로팅 단축키는 캡처 중의 현재 선택 영역, 또는 활성 편집창의 이미지를 우선 띄웁니다. 캡처 중 영역을 선택하지 않았다면 이전 클립보드나 닫은 이미지를 대신 띄우지 않습니다. 플로팅 단축키를 해제하면 F3도 동작하지 않으며 Ctrl+T 기본 동작은 유지합니다.
- 활성 플로팅 창을 닫는 단축키를 설정에서 변경하거나 해제할 수 있습니다. 기본값은 Esc이며 해당 이미지가 활성 상태일 때만 적용합니다. 이미지 도구 모음을 클릭한 뒤에도 닫기 키가 작동하도록 포커스를 수정했습니다. Ctrl+W, 더블클릭과 닫기 버튼도 계속 사용할 수 있습니다.

캡처·편집의 **플로팅** 명령은 이미지만 띄우며 클립보드 복사, 빠른 저장, 캡처 기록 추가를 실행하지 않습니다. 재실행 복원을 위한 플로팅 창 상태와 이미지 캐시는 유지합니다. **복사**나 **저장**을 선택했을 때의 동작 및 자동 플로팅 설정은 그대로 적용합니다.

## 사용

기존 앱을 트레이에서 종료한 뒤 새 `ChachaCapture.exe`를 실행하거나 앱의 업데이트 메뉴를 사용하세요.
설정 → 단축키에서 **선택 영역 / 클립보드 플로팅**, **활성 플로팅 창 닫기**의 입력란을 클릭하고 원하는 키를 누른 뒤 **설정 저장**을 선택합니다. 필요 없는 키는 **해제**를 누릅니다.

영역을 직접 지정하려면 설정 → 캡처의 **창과 화면 요소의 영역 자동 감지**를 끄세요.
이미지를 띄운 다음에는 이미지 또는 도구 모음을 클릭한 뒤 설정한 닫기 키로 닫을 수 있습니다.

저장소와 배포 파일은 공개되어 있습니다. GitHub 로그인 없이 EXE를 다운로드하고 앱 내 업데이트를 확인할 수 있습니다.

자체 검사 33개와 화면 캡처를 제외한 컨트롤러 검사 29개를 통과했습니다. 테스트 세션에서 Windows가 화면 접근을 거부해 실제 바탕화면 캡처와 수동 키 입력 검증은 완료하지 못했습니다.
