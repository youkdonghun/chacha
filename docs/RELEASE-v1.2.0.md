# Chacha Capture 1.2.0 · Windows x64

단축키 입력, 흰 화면 캡처 경로, 플로팅 표시 흐름을 수정하고 앱 안에서 업데이트하는 기능을 추가했습니다.

- 설정 입력란에서 실제 키를 누르면 Ctrl·Alt·Shift 조합을 인식합니다.
- 기능별 **지우기** 버튼으로 단축키를 해제할 수 있습니다. 전부 미지정이어도 저장되며 다시 실행해도 유지됩니다.
- 설정 중 앱 전역 단축키를 일시 해제하여 F1/F3 입력이 캡처·붙여넣기로 실행되지 않도록 했습니다.
- GPU Desktop Duplication을 기본으로 사용하고, 실패 시 GDI 호환 방식으로 전환합니다. GPU 우선 사용은 설정에서 끌 수 있습니다.
- GDI의 24-bit RGB 버퍼에서 화면 픽셀을 읽고 불투명 알파를 명시하며, 합성 완료를 기다린 후 캡처합니다.
- 기존 전체 화면 편집창·화이트보드를 캡처 전에 숨깁니다. 취소하면 복원하고, 성공하면 최소화하여 미완료 편집 내용을 보존합니다.
- Enter/Ctrl+C로 복사하거나 캡처 주석을 완료하면 기본적으로 플로팅 창이 열립니다. 설정에서 자동 플로팅을 끌 수 있습니다.
- 캡처·편집 화면이 닫힌 뒤 플로팅을 표시하고, 항상 위·불투명도·화면 내 위치를 복구합니다. Ctrl+T를 누를 때 창이 중복 생성되지 않습니다.
- **화면에 띄우기** 버튼과 플로팅 창의 편집·저장·닫기 도구 모음을 추가했습니다.
- 대시보드/트레이에서 **업데이트 확인 → 다운로드 → 설치하고 다시 시작**을 지원합니다. GitHub의 최신 정식 릴리스에서 파일을 받고 SHA-256·x64 형식을 확인합니다. 교체 실패 시 이전 EXE로 복구하며 설정·이미지를 유지합니다.

EXE 한 개로 실행합니다. 기존 실행 중인 버전은 트레이 → 종료 후 새 EXE를 실행하세요.
Windows 10/11 x64와 .NET Framework 4.8이 필요하며 기존 설정·기록을 유지합니다.

29개 자동 검사, 별도 실제 컨트롤러/화면 검사 34개, 업데이트 교체·복구 4개 경로를 통과했습니다. [검증 기록](https://github.com/youkdonghun/chacha/blob/main/docs/VALIDATION.md)
비공개 저장소 업데이트에는 이 PC의 GitHub CLI 로그인 또는 GH_TOKEN/GITHUB_TOKEN 환경 변수를 사용합니다.
사용자가 겪은 특정 외부 프로그램 조합은 프로그램명이 없어 동일 조건으로 재현하지 못했습니다.
Windows 캡처 도구를 호출하지 않지만 OS 캡처 감지나 보호 화면 차단을 우회하는 기능은 아닙니다.
