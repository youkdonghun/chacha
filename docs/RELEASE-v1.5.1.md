# Chacha Capture v1.5.1 · 호환 캡처 개선

v1.5.0의 호환 캡처에서 `0x80004005 / Win32=288`이 표시되었다는 보고를 바탕으로 GDI 화면 읽기 경로를 개선했습니다.

- 화면을 24비트 DIB에 바로 복사하던 경로를 장치 호환 비트맵 → 선택 해제 → 32비트 변환으로 변경했습니다.
- 반투명 창 포함 복사에서 오류 코드 0·50·87·288이 발생하면 기본 GDI 복사를 한 번 시도합니다. 기본 복사를 사용한 경우 반투명 창이 빠질 수 있음을 안내합니다. 접근 거부는 재시도하지 않습니다.
- 사용하지 않아도 되는 미러링 방지 비트 플래그를 제거했습니다. 이전 호출의 오류 값이 섞이지 않게 초기화하고, 실패한 API·모니터 좌표·재시도 결과를 진단에 남깁니다.
- 한글·영문 OCR과 기존 단축키·설정은 유지합니다.

자체 검사 38개와 실제 단일 모니터 화면을 사용하는 통합 검사 117개 assertion을 통과했습니다. 실제 GDI·DXGI 캡처, 단색 픽셀 보존, OCR과 기존 복사 흐름을 확인했습니다.
3840×1080 / 왼쪽 원점 -1920 좌표 및 오류 288 후 재시도는 메모리 DC와 오류 주입으로 검사했습니다. 보고된 사용자의 실제 듀얼 모니터·드라이버 환경에서 같은 오류가 해결되는지는 추가 확인이 필요합니다.

기존 앱을 트레이에서 종료하고 새 `ChachaCapture.exe`를 실행하거나 **업데이트 확인**을 사용하세요.
오류가 계속되면 **설정 → 캡처 → 최근 캡처 진단 복사**의 새 내용을 확인해 주세요.
