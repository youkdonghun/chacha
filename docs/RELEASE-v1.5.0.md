# Chacha Capture v1.5.0 · 한글·영문 텍스트 추출

캡처 이미지에서 한글·영문·숫자와 `? ! % @ :` 같은 기호를 읽고, 수정해서 복사할 수 있습니다.

- 캡처 영역 선택 → **텍스트**, 편집창 → **텍스트 추출**, 고정 이미지 우클릭 → **텍스트 추출…**
- 세 화면 모두 **Ctrl+Shift+O** 지원
- 작은 글자 확대, 어두운 배경 대비 보정, 문단·자동·한 줄 읽기
- 결과 직접 수정, 선택한 텍스트 복사와 전체 복사
- 이미지·텍스트를 외부로 전송하지 않는 로컬 처리; EXE에 한글·영문 모델 포함
- 인식 완료·취소·시간 초과 시 전용 프로세스 종료, 대기 중 OCR 엔진 메모리 미사용
- OCR 실행으로 이미지 기록·자동 저장·새 플로팅을 생성하지 않고, 텍스트 복사 후 원본 이미지 창 유지

기존 앱을 트레이에서 종료한 뒤 새 `ChachaCapture.exe`를 실행하거나 앱의 **업데이트 확인**을 사용하세요.
Windows 10/11 x64, .NET Framework 4.8 및 OCR용 Microsoft Visual C++ x64 런타임이 필요합니다.

자체 검사 37개와 실제 Form·클립보드를 사용하는 동작 검사 92개 assertion을 통과했습니다.
혼합 문장과 필수 기호는 밝고 어두운 배경·14/20/28px의 6개 합성 조건에서 확인했습니다. 작은 영문과 괄호 등에는 오인식이 남으므로 복사 전에 결과를 확인하세요.
바탕화면 전체 캡처와 실제 혼합 DPI 다중 모니터 환경의 수동 검증은 포함하지 않습니다.
