# Chacha Capture v1.5.3 · 숫자와 영문 OCR 개선

- 자동 읽기는 한글 인식 뒤 영문·숫자 단어를 같은 이미지 위치에서 다시 읽습니다. 한글 단어와 기호만 있는 단어는 유지하며, 수량이 영문 단어로 바뀌거나 구두점이 추가되지 않도록 제한합니다.
- **영문·숫자·코드**, **숫자·기호만** 선택을 추가했습니다. 두 모드는 별도 고정밀 영문 모델을 사용합니다. 숫자 모드는 숫자와 `. , : % + - / ( )`만 읽으며 한글·영문은 제외합니다.
- 두 번 읽은 결과가 달라 변경한 단어는 결과 창에서 대조할 수 있게 안내합니다. `0→O`, `S→8` 같은 문자열 일괄 치환은 하지 않습니다.
- v1.5.2의 캡처 복구, 한글·기호 인식, 로컬 처리, 취소와 작업 프로세스 종료는 유지합니다.

합성 이미지 18개 조건에서 공백을 제외한 문자 편집 거리가 244에서 169로 줄었습니다. 별도 글꼴·문장 8개 조건에서는 67에서 56으로 줄었습니다. 모든 화면의 정확도 수치가 아니며, 일부 코드·이메일의 0/O/o·1/I/l 혼동은 남습니다.

원본이 번호나 금액만 담고 있으면 텍스트 종류를 **숫자·기호만**으로 바꾸고 **다시 읽기**를 누르세요. 영문 코드와 이메일에는 **영문·숫자·코드**를 사용하세요.

기존 앱을 종료한 뒤 새 `ChachaCapture.exe`를 실행하세요. 자세한 비교와 검증 범위는 [OCR 비교 기록](OCR-COMPARISON.md), [검증 기록](VALIDATION.md)에 있습니다.
