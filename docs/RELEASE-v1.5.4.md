# Chacha Capture v1.5.4 · GPU 첫 화면 수신 수정

v1.5.3에서 GDI 오류 288 뒤 GPU로 전환했지만 두 모니터 모두 `present=False`인 단색 화면을 성공으로 반환한 문제를 수정합니다.

- 새 GPU 캡처 연결에서 마우스 정보만 갱신된 프레임은 복사하지 않고 반환한 뒤, 실제 화면 갱신이 있는 프레임을 기다립니다.
- 각 모니터의 첫 화면 대기는 최대 1초, 전체 GPU 캡처의 대기 예산은 3초입니다. 기존 120ms 한 번 수신과 900ms 전체 제한을 개선했습니다. 무한 대기나 백그라운드 캡처 연결은 두지 않습니다.
- 끝내 화면 갱신을 받지 못하면 성공한 단색 이미지로 넘기지 않고 시간 초과와 해당 모니터를 진단에 남깁니다. 정상 화면 갱신으로 받은 흰색·회색·검은색 이미지는 그대로 보존합니다.
- 진단에는 모니터별 시도 횟수, 건너뛴 프레임, 시간 초과 횟수와 대기 시간이 추가됩니다.

자체 검사 41개와 실제 화면 통합 검사 133개를 통과했습니다. GDI 288과 첫 GPU 프레임 문제를 함께 주입한 검사에서는 두 번째 실제 화면의 변경된 색상과 주변 픽셀을 정확히 읽었습니다.

이 수정은 실제 데스크톱 갱신이 없는 첫 프레임을 받아들이던 코드 결함을 다룹니다. 사용자 PC의 GDI 오류 288 자체나 듀얼 모니터 드라이버 문제의 완전한 해결을 보장하지 않습니다.

기존 차차를 트레이에서 완전히 종료한 뒤 새 `ChachaCapture.exe`를 실행하세요. [검증 기록](VALIDATION.md)을 참고하세요.
