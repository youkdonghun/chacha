# Snipaste 기능 대조표 · v1.4.0

기준: 2026-09-10에 확인한 Snipaste Windows 무료판 공식 문서.
'구현'은 대응 기능이 있다는 뜻이며, 원본과 모든 픽셀·예외 상황이 동일하다는 뜻은 아닙니다.

| 영역 | 구현한 동작 | 차이·제약 |
|---|---|---|
| 캡처 | F1, 트레이, 지연·전체·최근·정확한 영역 | 모든 마우스 동작 사용자 지정은 미지원 |
| 감지 | 켜면 창·UI Automation 요소·Tab·휠 탐색, 끄면 직접 드래그만 선택 | 꺼짐에서는 창·요소 조회와 클릭 자동 선택을 하지 않음; 켜짐의 요소 감지는 접근성 제공자에 의존 |
| 픽셀 제어 | 영역 이동·크기, WASD, 확대경, RGB/HEX | HDR 색 관리 미검증 |
| 완료 | Enter/Ctrl+C 복사 후 자동 플로팅, 지정 플로팅 키/Ctrl+T로 현재 이미지만 플로팅, 저장·빠른 저장·인쇄 | 명시적 플로팅은 클립보드·빠른 저장·캡처 기록을 변경하지 않음; 재실행 복원 캐시는 유지 |
| 플로팅 단축키 | 캡처 선택 영역·활성 편집 이미지를 우선 사용, 그 외에는 닫은 이미지 복구·클립보드 붙여넣기 | 캡처 중 무선택이면 아무 동작 없음; 단축키 해제 시 F3도 미동작, Ctrl+T 로컬 동작 유지 |
| 캡처 방식 | 자동은 GDI 우선, GDI/DXGI 명시적 선택, 불투명 화면 픽셀 | 명시 모드는 선택 API만 사용; 접근 거부·보호 콘텐츠를 우회하지 않음 |
| 캡처 진단 | 사용한 방식·화면 크기·API 오류 복사, 단색 화면·보호 콘텐츠 안내 | 회사 보안 프로그램의 모든 조합은 미검증; 단색만으로 실패나 차단 여부를 판정하지 않음 |
| 캡처 커서 | 커서 별도 표시·숨기기, GPU에 포함된 커서 중복 방지 | GPU가 포인터를 화면에 포함하면 제거하려면 GDI 방식을 선택해야 함 |
| 단축키 설정 | 클릭 후 실제 키 조합 즉시 인식·안내, 설정 저장으로 적용, 기능별 해제·미지정 | Windows 키 조합은 미지원; 5개 전역 단축키의 등록 충돌은 저장 전에 확인, 플로팅 닫기는 활성 창 안에서만 적용 |
| 기록 | 쉼표·마침표, 원래 화면 좌표, 개수 제한 | 저장 영역을 현재 고정 배경 위에 재구성; 당시 전체 바탕화면은 보관하지 않음 |
| 주석 | 도형·선·화살표·꺾은선·펜·형광펜·문자·번호·모자이크·흐림·지우개·자르기; 캡처 위 도구에도 한국어 이름 표시 | UI 요소 오른쪽 클릭으로 자동 주석 생성은 미구현 |
| 주석 수정 | 이동·크기·문자 회전·색상·알파·굵기·채움·undo/redo/초기화 | 모든 도구별 미세 설정과 동일하지 않음 |
| 붙여넣기 | 이미지·텍스트·RGB/HEX·HTML/RTF·파일·TGA | HTML은 기본 텍스트 서식; CSS 레이아웃·웹 이미지 미지원 |
| 고정 창 | 이동·회전·반전·배율·불투명도·접기·정렬·클릭 통과·드롭·원문 복사 | 화면 밖 복원 시 현재 모니터 안으로 보정 |
| 닫기·숨기기 | 활성 창 닫기 키 지정·해제(기본 Esc), Ctrl+W 복구 가능한 닫기, 지정 플로팅 키로 복구, Shift+F3 전체 숨기기, Shift+Esc 제거 | 닫기 키는 전역 단축키가 아님; 도구 모음 클릭 후에도 해당 이미지 키 입력 유지; 기본 보관 1개, 최대 100개 |
| 고정 창 편집 | 원래 위치·배율에서 도구 모음으로 편집 후 반영 | 편집은 현 프레임을 정적 이미지로 전환; 세션 간 주석 객체 재편집 미지원 |
| GIF | 재생·정지·프레임·속도·회전·반전·복원 | 애니메이션 주석·변환 GIF 인코딩 미지원 |
| 그룹 | 생성·전환·이름 변경·선택 이동·내보내기/가져오기 | Chacha 전용 파일, Snipaste 그룹·설정 파일 불호환 |
| 화이트보드 | 화면 배경 위 주석, Space 도구 모음, Esc 무시 | PRO 투명 화이트보드 미지원 |
| 명령행 | 주요 snip/paste/group/whiteboard/트레이 | --hold, --block, 그림자, 파일명 변수, 출력 조합·exec 미지원 |
| PRO | 일부 직접 재편집·다중 선택 포함 | OCR, QR/바코드, 가상 데스크톱 연동, 핫코너 등 미구현 |
| UI | 둥근 버튼·카드·입력란, 한국어 대시보드·그룹·탭 설정·도구 모음, 문자 입력창 여백 | 원본 테마·레이아웃·아이콘과 동일하지 않음 |
