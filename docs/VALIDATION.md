## 실제 EXE 조작

`--data-dir`로 지정한 테스트 전용 프로필에서 다음 흐름을 확인했습니다.

1. 한국어 대시보드와 설정의 4개 탭: 버튼·설명·입력란 잘림 없이 표시
2. F1 → 실제 화면에서 영역 드래그 → 271×157 선택 → Enter: 복사 및 종료, 정확한 기록 좌표 저장
3. 클립보드 붙여넣기로 271×157 고정 이미지 생성
4. 재실행 후 같은 이미지·위치·배율 복원
5. 고정 이미지에서 Space: 동일 위치에서 도구 모음 표시, 바깥 배경을 가리지 않음
6. 화살표 그리기 → Ctrl+Z → Ctrl+Y → Space: 주석 반영 및 같은 크기의 고정 창 복귀
7. Esc로 닫은 이미지가 닫힘 상태로 저장됨, F3로 같은 이미지 복구
8. Shift+F3 숨기기는 닫힘 상태와 구분됨

그룹 관리 창의 처음 표시 시 ImageList가 해제된 썸네일을 지연 참조하는 오류를 발견하여,
썸네일 추가 전에 네이티브 ImageList를 생성하도록 수정했습니다. 최종 그룹 창 및 컨트롤러 검증 결과는 아래에 덧붙입니다.

UI 자동화가 작은 핀 창을 찾을 수 있도록 테스트 실행의 `--ui-test` 옵션으로만 해당 창을 작업 표시줄에 노출했습니다.
일반 실행에서는 원래대로 작업 표시줄을 차지하지 않습니다.

## 확인하지 못한 환경

실제 혼합 DPI 다중 모니터, HDR, 원격 데스크톱, 보호된 영상 및 보안 데스크톱은 이 환경에서 검증하지 못했습니다.
프린터 대화상자 코드는 구현되어 있으나 실제 종이 출력은 수행하지 않았습니다.
이 문서는 Snipaste 전체 제품의 호환성 인증이 아닙니다. 세부 기능 차이는 PARITY.md에 있습니다.

## 최종 컨트롤러 통합 검사

실제 CaptureApplication을 임시 프로필에서 실행한 별도 37개 검사를 통과했습니다.
GIF를 편집 창에서 열고 수정 없이 닫으면 원본·프레임·일시정지 상태가 유지됩니다.
저장 후 모든 편집을 실행 취소하고 닫아도 초기 이미지·배율·위치가 유지됩니다.
그룹 전환과 전체 숨기기는 열려 있는 핀 편집을 반영하고 닫습니다.
자른 영역의 실제 원점이 최근 선택 영역과 기록에 저장됩니다.
GroupsForm.Show에서 네이티브 ImageList/ListView 생성과 썸네일 렌더가 정상입니다.
종료 직전의 편집도 최종 PNG·배율·위치로 저장됩니다.
검사 후 테스트 컨트롤러·프로세스·임시 프로필은 정리했습니다.

최종 EXE 재검증에서 그룹 창의 정상 썸네일 표시와 화이트보드의 초기 도구 모음 숨김,
Esc 유지, Space 표시 전환을 확인했습니다. 그룹 관리 하단 버튼의 줄바꿈 간격도 보정했습니다.
