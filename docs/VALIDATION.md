- 별도 앱이 앞에 있는 상태에서 Ctrl+Shift+F9를 누르면 캡처 시작

## 실제 EXE 조작

테스트 전용 프로필에서 Ctrl+Shift+F9 실제 입력, Enter 입력, Esc 복원, 개별 지우기와 저장을 확인했습니다.
새 단축키로 캡처를 시작하고 263×224 영역을 선택해 Enter로 완료했을 때 독립 플로팅 창이 생성됐습니다.
플로팅 창 드래그, 도구 모음 표시, 앱 재실행 후 이미지·설정 복원을 확인했습니다.
Snipaste가 함께 실행된 환경에서 겹치지 않는 단축키를 사용했습니다.

실제 업데이트 창에서 비공개 GitHub 저장소 인증·최신 버전 조회·릴리스 노트 표시를 확인했습니다.
서비스 별도 검사에서는 테스트 앱 1.0.0이 실제 릴리스 1.1.0의 EXE 255,488바이트를 내려받아 SHA-256·AMD64·어셈블리 이름/버전을 검증했습니다.
이 다운로드 검사에서는 설치하지 않았고, 검사 후 임시 다운로드를 정리했습니다. 인증값은 출력·저장하지 않았습니다.

임시 설치 폴더의 실제 1.0/2.0 EXE를 사용한 업데이트 도우미 검사:

- 정상 1.0 → 2.0 교체 및 재시작
- 성공 후 백업 정리 실패가 발생해도 정상 설치 상태 유지
- 새 EXE가 시작 직후 종료되면 이전 EXE 바이트 복구 및 실패 안내 전달
- 준비 완료 후 파일을 변조하면 설치 거부, 이전 EXE 유지 및 실패 안내 전달

각 경로에서 원래 프로세스의 PID·시작 시각·실행 경로 확인과 준비 완료 응답을 사용했습니다.
사용자 작업 폴더의 EXE를 위 테스트로 교체하지 않았습니다.
