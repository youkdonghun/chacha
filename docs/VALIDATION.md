# v1.0.0 검증 기록

2026-09-10, Windows x64 / .NET Framework 4.8 / 1920×1080 단일 모니터에서 확인했습니다.

## 자동 검사

`build.ps1 -Test`의 13개 검사 통과:

- 설정 XML 왕복, 원자적 교체와 실패 시 기존 파일 보존
- 손상된 설정 복구, 기록 개수 범위 제한
- 고정 창 정보 및 배율 저장·복원, 잘못된 경로 거부
- 캡처 기록 순환 보관과 PNG 픽셀 보존
- 클립보드 접근 없는 HEX/RGB 파싱, 텍스트 렌더링
- 전역 단축키 구문 분석 및 잘못된 키 거부
- 고정 이미지 원본 소유권 분리, 회전·반전, 클릭 통과
- 원본 크기의 편집기 이미지 복제 및 자르기 실행 취소·다시 실행
- 지정 영역 안에서만 작동하는 모자이크 및 흐림 처리
- 테스트 임시 폴더 정리

별도로 캡처 소스에서 실제 데스크톱 취득, 선택 영역 렌더링, 음수 원점 좌표,
25×30 선택 영역의 정확한 원본 픽셀 일치를 검사했습니다.
EXE의 PE Machine 필드 `0x8664`(AMD64)를 확인했습니다.

## 실제 앱 조작

별도 테스트 프로필로 앱을 실행하여 확인한 흐름:

1. 대시보드와 설정 창의 한국어 레이아웃 확인
2. F1 → 화면에서 영역 드래그 → Enter → 편집기, 원본 크기 241×321 확인
3. 화살표 주석 → Ctrl+Z → Ctrl+Y로 지우기 및 복원
4. Ctrl+P로 고정 창 생성
5. Ctrl+C → F3으로 클립보드 이미지의 추가 고정 창 생성
6. Ctrl+F3으로 모든 고정 창 숨김
7. 재실행 후 캡처 기록과 저장된 고정 창 상태 복원
