Windows 64비트용 Chacha Capture 첫 버전입니다.

**ChachaCapture.exe** 하나를 내려받아 실행하거나 ZIP을 압축 해제하세요. Windows 10/11 x64, .NET Framework 4.8이 필요합니다.

- F1 영역 캡처, F3 클립보드 고정, Ctrl+F3 고정 창 숨기기/표시
- 도형·화살표·텍스트·모자이크·흐림·자르기, 실행 취소/다시 실행
- 고정 이미지 이동·확대·회전·반전·투명도·클릭 통과
- 캡처 기록, 고정 창 복원, 한국어 설정과 트레이 메뉴

독립 구현으로 Snipaste의 모든 기능과 1:1 호환되지는 않습니다. 상세 범위와 사용법은 README를 확인하세요.

자동 검사 13개 및 실제 캡처→편집→복사→고정 흐름을 검증했습니다. SHA256SUMS.txt로 EXE 체크섬을 확인할 수 있습니다.
