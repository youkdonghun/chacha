# Chacha Capture v1.4.1 · Windows x64

캡처 후 **Ctrl+C**로 복사했는데 플로팅 이미지가 화면에 남던 문제를 수정했습니다.

- 캡처 영역과 그리기 화면에서 Ctrl+C 또는 복사 버튼을 누르면 클립보드에 복사하고 닫습니다. 기존 설정에서 자동 플로팅을 켜 두었어도 새 플로팅 창을 띄우지 않습니다.
- 이미 떠 있는 플로팅 이미지에서 Ctrl+C를 누르면 해당 이미지만 닫습니다. 그 이미지를 편집하는 중에 복사해도 원래 플로팅 창이 다시 나타나지 않습니다.
- 클립보드 복사 성공을 확인한 뒤 닫으며, 복사 실패 시 이미지를 유지합니다. 닫은 플로팅 이미지는 복구할 수 있고 다른 플로팅 이미지는 영향을 받지 않습니다.
- Enter·더블클릭·저장 완료의 자동 플로팅 설정과 지정 플로팅 단축키는 유지합니다. 화면 안내도 Ctrl+C의 복사 후 닫기 동작에 맞게 바꿨습니다.

## 사용

앱의 **업데이트 확인 → 다운로드 → 설치하고 다시 시작**을 사용하거나, 기존 앱을 트레이에서 종료하고 새 `ChachaCapture.exe`를 실행하세요.
저장소와 배포 파일은 공개되어 있어 GitHub 로그인 없이 다운로드할 수 있습니다.

자체 검사 34개와 합성 이미지·실제 Form·클립보드를 사용하는 동작 검사 77개 assertion을 통과했습니다. 실제 바탕화면 캡처를 포함하는 검사는 Windows 접근 거부로 완료하지 못했습니다.
검증 범위와 결과: [검증 기록](https://github.com/youkdonghun/chacha/blob/main/docs/VALIDATION.md).
