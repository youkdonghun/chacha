# Chacha Capture

Windows에서 **캡처 → 주석 → 화면 고정**을 빠르게 이어가는 개인용 캡처 프로그램입니다.
Snipaste의 작업 흐름을 참고한 독립 구현이며, Snipaste 코드·브랜드·이미지를 포함하지 않습니다.

## 실행

`ChachaCapture.exe`를 실행하세요. **Windows 10/11 x64 + .NET Framework 4.8** 환경을 대상으로 합니다.
설치 프로그램이나 관리자 권한은 필요하지 않습니다. EXE 하나로 실행되며, 사용 기록은 아래 사용자 폴더에 보관됩니다.

대시보드를 닫아도 트레이에서 실행됩니다. 완전히 끝내려면 **트레이 우클릭 → 종료** 또는 대시보드의 **종료** 버튼을 사용하세요.

## 기본 단축키

| 동작 | 단축키 |
|---|---|
| 영역 캡처 | **F1** |
| 클립보드 이미지·텍스트·색상표 고정 | **F3** |
| 고정 창 전체 숨기기 / 표시 | **Ctrl+F3** |
| 캡처 선택 후 편집 | **Enter** |
| 선택 영역 바로 복사 / 저장 / 고정 | **Ctrl+C / Ctrl+S / Ctrl+P** |
| 캡처 중 커서 위치 HEX 색상 복사 | **C** |
| 캡처 중 최근 선택 영역 불러오기 | **R** |
| 선택 영역 1픽셀 이동 / 크기 조정 | **방향키 / Shift+방향키** |
| 취소 | **Esc** |

다른 프로그램이 F1/F3를 사용하는 경우 설정에서 `Ctrl+Shift+A` 같은 단축키로 변경할 수 있습니다.
단축키 등록에 실패하면 알림이 표시되고 트레이 메뉴는 계속 사용할 수 있습니다.

## 주요 기능

- 가상 데스크톱 전체의 영역 캡처, 다중 모니터 좌표 및 DPI 인식
- 창 영역 자동 감지, 선택 영역 이동·8방향 크기 조정, 픽셀 확대경, HEX/RGB 표시
- 전체 화면, 3초 지연, 최근 영역 다시 캡처, 커서 포함 옵션
- 사각형·타원·선·화살표·자유 펜·형광펜·텍스트·순서 번호 주석
- 모자이크·흐림 처리·주석 지우개, 실행 취소·다시 실행, 자르기, 확대·축소
- PNG/JPEG/BMP 저장, 원본 픽셀 크기로 클립보드 복사
- 항상 위에 떠 있는 이미지 고정 창, 드래그·확대·회전·반전·투명도·클릭 통과
- 이미지 파일 드롭, 클립보드 이미지·이미지 파일·텍스트·HEX/RGB 색상표 고정
- 최근 캡처 기록(기본 50개, 1–200개), 고정 창 자동 저장 및 다음 실행 시 복원
- 한국어 대시보드, 트레이 메뉴, 단축키 및 저장 폴더 설정

### 고정 창 조작

| 동작 | 조작 |
|---|---|
| 이동 | 이미지 드래그 |
| 확대 / 축소 | 마우스 휠 또는 `+` / `-` |
| 불투명도 조절 | `Ctrl` + 마우스 휠 |
| 왼쪽 / 오른쪽 회전 | `1` / `2` |
| 좌우 / 상하 반전 | `3` / `4` |
| 편집 | `Space` |
| 숨기기 | 더블 클릭 또는 `Esc` |
| 썸네일로 접기 | `Shift` + 더블 클릭 |
| 복사 / 저장 / 닫기 | `Ctrl+C` / `Ctrl+S` / `Ctrl+W` |
| 추가 기능 | 우클릭 메뉴 |

숨겨진 창 또는 클릭이 통과하는 창은 **트레이 → 고정 창 표시 및 클릭 통과 해제**로 복구할 수 있습니다.
고정 창에서 편집한 뒤 편집기의 고정 버튼을 누르면 해당 창의 이미지가 바뀝니다.

## 저장 위치

- 설정·기록·고정 창: `%LOCALAPPDATA%\ChachaCapture`
- 기본 이미지 저장 폴더: `%USERPROFILE%\Pictures\Chacha Capture` (실제 Windows 사진 폴더 경로 사용)
- 오류 기록: `%LOCALAPPDATA%\ChachaCapture\error.log`
- 캡처 기록 저장을 끄면 이후 캡처를 기록하지 않습니다. 이미 저장된 기록은 유지됩니다.
- 이 앱에는 네트워크 요청, 계정 로그인, 원격 업로드 기능이 없습니다.

## 범위

이 버전은 Snipaste의 모든 기능과 1:1 호환되는 복제품은 아닙니다. 스크롤 캡처, OCR, GIF 애니메이션 재생,
HTML 서식 유지, UI 컨트롤 단위 감지, 이미지 그룹은 포함하지 않습니다. GIF를 열면 첫 프레임을 사용합니다.
보호된 영상, 보안 데스크톱, 일부 HDR 콘텐츠는 일반 Windows 화면 캡처와 동일한 제한이 있습니다.
혼합 DPI·음수 좌표 처리를 구현했지만 실제 다중 모니터 구성은 별도 검증이 필요합니다.

## 소스에서 빌드

Windows PowerShell에서:

```powershell
.\build.ps1 -Test
```

Windows에 있는 Framework64 C# 컴파일러로 C# 5 소스를 빌드합니다. .NET SDK, NuGet, Node.js가 필요하지 않습니다.
결과물은 `dist\ChachaCapture.exe`와 `dist\ChachaCapture-1.0.0-win-x64.zip`입니다.
자체 테스트 결과와 SHA-256 체크섬도 `dist`에 생성됩니다. GitHub Actions에서도 같은 명령을 실행합니다.

```powershell
# 테스트 전용 별도 프로필
.\dist\ChachaCapture.exe --data-dir C:\Temp\ChachaTest
# 트레이로 시작
.\dist\ChachaCapture.exe --tray
# 이미지 파일 편집
.\dist\ChachaCapture.exe --open C:\Pictures\sample.png
```
